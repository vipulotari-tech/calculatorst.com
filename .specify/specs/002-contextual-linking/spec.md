# Spec: Content Depth & Contextual Internal Linking

## Problem
All 201 calculator pages currently show the same 6 related calculators from the same cluster. A concrete slab page shows 5 other concrete calculators. A user pouring a slab also needs rebar, gravel base, and possibly excavation — but never needs concrete-mix or concrete-tube. Related calculators should reflect real construction workflows, not mechanical cluster membership.

Additionally, calculator descriptions (auto-generated by `calculator-content.ts`) are mathematically accurate but may not capture search-intent-specific language that distinguishes a calculator from its siblings.

## Goals
1. Each calculator page links to 2-6 genuinely related calculators based on construction workflow adjacency
2. No calculator shows the same 6 related links as every other calculator in its cluster
3. Related calculators reflect what a user with this specific task would next need
4. Category hub pages list all calculators with working links and descriptions

## Non-Goals
- Changing calculator formulas or model logic
- Changing page routing or URL structure
- Adding new calculators
- Changing title tags or meta descriptions (separate spec)
- Content regeneration (handled by calculator-content.ts)

## Affected Pages
All 201 calculator pages (generic component via `src/pages/[slug]/index.astro`) and all category hub pages (`src/pages/construction/[category]/index.astro`).

## User Intent
A user on a specific calculator page is mid-workflow. They need the next logical tool in their construction planning sequence.

## Internal Linking Requirements
Build a workflow adjacency map:

**Concrete Slab** → Rebar, Gravel (base), Concrete Cost
**Concrete Footing** → Excavation, Rebar, Foundation Wall
**Concrete Column** → Rebar, Concrete Slab (deck on columns)
**Rebar** → Concrete (any), Rebar Weight, Rebar Spacing
**Brick** → Mortar, Brick Cost, Brick Veneer
**CMU** → CMU Mortar, CMU Grout, Rebar (reinforcement)
**Gravel** → Gravel Cost, Asphalt, Paver Base
**Asphalt** → Asphalt Cost, Gravel (base), Parking Lot
**Roofing** → Roof Sheathing, Roof Flashing, Shingles
**Flooring** → Underlayment, Tile Grout, Flooring Waste
**Drywall** → Paint, Drywall Joint Compound, Insulation
**Framing** → Deck, Beam, Board Foot
**Deck** → Deck Railing, Deck Footing, Fence
**Fence** → Fence Concrete, Gate, Deck
**Paver** → Paver Sand, Paver Base, Landscaping
**Mulch** → Landscaping, Gravel
**Excavation** → Fill Dirt, Foundation, Trench

## Technical Approach
Add a `relatedCalculators` field to `hubCalculators.ts` entries (or create a new adjacency map in `src/lib/`). The generic calculator page reads from this instead of computing from cluster alone.

## Acceptance Criteria
1. ✓ Each calculator page shows 2-6 related calculators
2. ✓ No two calculators in the same cluster show identical related sets (unless genuinely appropriate)
3. ✓ Every related link points to an existing calculator page
4. ✓ Related calculators reflect construction workflow adjacency
5. ✓ Category hub pages show all calculators in category with working links
6. ✓ Build succeeds, no broken links
